# Калькулятор клея БОЛАРС

Статический сайт: откройте index.html или разместите на GitHub Pages.

Расчёты сохраняются локально в браузере пользователя. Ссылка на расчёт переносит выбранный продукт, площадь, расход и массу мешка.

Публикация: Settings → Pages → Deploy from a branch → main / (root) → Save.
